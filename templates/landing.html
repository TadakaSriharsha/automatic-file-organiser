GOOD TO KNOW

Questions, answered.

Does FileFlow change my original files?

No. Uploaded files are stored in your private FileFlow workspace and organized as copies. Files are never overwritten when names collide.

What happens when I delete a file?

Moving a file to Trash keeps it available for restore. Permanent deletion is a separate action and cannot be undone.

What file types can I preview?

FileFlow previews common image formats, PDFs, and supported text formats. Other files can still be downloaded.

Are my files kept after a Render restart?

The included free Render configuration uses ephemeral storage. Configure a persistent disk and point FILEFLOW_DATA_DIR and FILEFLOW_DB_PATH to it for durable production storage.
